Data Pipeline
Alpha & Bravo

The notebook starts by loading four CSV files — generation and weather sensor data for each plant — then cleans and merges them into analysis-ready DataFrames for Alpha and Bravo.

  • Load Plant_1 and Plant_2 generation data
  • Load corresponding weather sensor data for each plant
  • Standardize timestamps (e.g., DATE_TIME → DT_ROUND)
  • Merge generation + weather on rounded datetime
  • Filter to daytime rows (irradiation > 0.1, DC power > 10)

Modeling Approach
Random Forest

For each plant, the cleaned data is split into a training window and a test window based on date. A RandomForestRegressor is then trained to predict DC_POWER from core weather features.

  • Convert DT_ROUND to datetime and sort by time
  • Use initial block of days for training, following days for testing
  • Feature set includes IRRADIATION and MODULE_TEMPERATURE
  • Train RandomForestRegressor per plant
  • Evaluate with RMSE and R² on test sets

Building a Reusable Solar Output Prediction Workflow

Starting from raw CSV files for two separate plants, this project assembles a repeatable workflow: ingest generation and weather sensor data, align timestamps, filter to meaningful daytime observations, train a RandomForest model on irradiation and module temperature, and evaluate test performance. The end result is a template for extending to more features, plants, and forecasting horizons.

Core features
2+
Solar irradiation and module temperature form the backbone of the DC power prediction model, with room to add more weather and time-based features.
Scalability
Multi-plant
The same cleaning, merging, and modeling pattern works for Alpha, Bravo, and any additional plants — making this a solid base for a larger solar forecasting platform.

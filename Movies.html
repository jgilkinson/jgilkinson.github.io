Data Pipeline
movies_small & ratings_small

The notebook begins with a simple loader function that pulls in movies_small.csv and ratings_small.csv, then merges average ratings back onto the movies table to enrich the catalog.

  • Load movies and ratings from local CSV files
  • Group ratings by movieId to compute mean rating
  • Merge mean rating into the movies DataFrame
  • Return a single, enriched table for modeling
pandas ETL rating aggregation enriched movie catalog
Recommendation Logic
TF-IDF & cosine

A TF-IDF vectorizer converts each movie’s genre string into a numeric feature vector. Cosine similarity between these vectors defines which movies are “close” to a given title in genre space.

  • Fit TfidfVectorizer on the movie genres
  • Compute a cosine similarity matrix across all movies
  • Find the index of the user-selected movie title
  • Sort all other movies by similarity score
  • Return the top 10 most similar titles (excluding the seed movie)
content-based filtering cosine similarity top-N recommendation

From CSVs to a Genre-Aware Recommender

This assignment turns two small CSV files into a working movie recommendation engine: ratings are aggregated and merged into the movie catalog, genres are vectorized with TF-IDF, and cosine similarity powers a top-N neighbor lookup for any seed title. The result is a compact, readable example of a content-based recommender that can be extended with more features, hybrid models, or a web front-end.

Core ingredients
TF-IDF + cosine
Genre text becomes a numeric representation, and cosine similarity turns that representation into “movies like this one” recommendations.
Output
Top 10
For each input title, the system returns ten similar movies, enabling simple watch-next suggestions anchored in shared genre patterns.

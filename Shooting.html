Understanding Patterns in Shooting Incidents

This notebook analyzes a dataset of reported shooting incidents to understand when and where they occur and which factors are associated with more severe outcomes. After exploring trends across time, location, and victim counts, the project builds a predictive model to distinguish higher-risk events and highlight features that contribute most to incident severity.

Dataset & Features
shooting records

The notebook loads a dataset of shooting incidents with fields capturing when and where each event occurred and how many people were harmed. Basic cleaning ensures date, numeric, and categorical fields are in consistent formats for analysis and modeling.

  • Load data into a pandas DataFrame
  • Convert string dates to datetime and extract year/month/hour features
  • Ensure counts of injured and killed are numeric
  • Create derived fields like total victims or incident severity class

Exploratory analysis focuses on how shootings vary across time, place, and severity. Visualizations highlight when incidents spike and which combinations of features are more common in severe cases.

Modeling & Evaluation
risk modeling

The modeling stage treats incident severity (or a related outcome) as the target. The notebook splits the data into train and test sets, encodes categorical variables, and fits a classification model to predict higher-risk shootings based on the available features.

  • Define predictors (time, location, victim counts, context fields) and target label
  • Use train_test_split to create held-out evaluation data
  • Fit a classifier (e.g., logistic regression or tree-based method)
  • Evaluate using precision, recall, F1, ROC AUC, and a confusion matrix

From Descriptive Patterns to Predictive Insight

This project begins with descriptive questions: how often do shooting incidents occur, how severe are they, and how do those patterns change over time and across locations? After cleaning and visualizing the data, the notebook moves into modeling, using a classification algorithm to distinguish higher-severity incidents from less severe ones. The emphasis is on interpretable metrics that show where the model performs well and where there is room for improvement.

Trends & risk
